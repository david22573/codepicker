# CodePicker Refactor Roadmap

**Mission**: Rebuild CodePicker from a 20k LOC monolith into a maintainable 2k LOC system using Hexagonal Architecture.

## 🛑 Core Rules (Non-Negotiable)
1.  **Hexagonal Architecture**: Domain imports NOTHING. Infra imports Domain.
2.  **Shadow Filesystem**: All writes go to `.codepicker/shadow/` first.
3.  **No Global State**: Dependencies injected via constructors.
4.  **Single Responsibility**: Functions < 50 lines, Structs < 7 fields.

---

## 📅 PHASE 1: Foundation & Cleanup
**Goal**: Establish clean architecture and remove hazardous code.

- [ ] **1.1 Delete Hazardous Code**
    - [ ] Delete `internal/agent/recovery.go` (Unsafe auto-recovery)
    - [ ] Delete `internal/agent/orchestrator.go` (Redundant)
    - [ ] Delete `internal/database/relevance.go` (Unproven optimization)
    - [ ] Delete `internal/prompts/prompts.go` (Will externalize)
- [ ] **1.2 Create Package Structure**
    - [ ] `domain/{agent,task,errors}`
    - [ ] `infra/{llm,storage,shell}`
    - [ ] `adapters/{tools,prompts,policy}`
    - [ ] `app/` and `cmd/`
- [ ] **1.3 Define Domain Interfaces**
    - [ ] `domain/agent/agent.go` (Agent, Tool, Policy interfaces)
    - [ ] `domain/agent/execution.go` (State machine structs)
    - [ ] `domain/task/task.go` (Task, Plan, Step value objects)
- [ ] **1.4 Verification**
    - [ ] `go build ./...` passes (even with empty implementations)
